## 设计结论

保留「家庭保卫战」的明快色彩和家人一起劳动的品牌插画，减少粗边框、厚重阴影与大表单。欢迎和登录成为同一幅完整画面；资料创建采用一页一件事。不是增加一套强制翻页的广告，而是让每次填写都有反馈。

创意主线：把小家一步步组起来。家庭名出现到门牌，昵称出现在人物旁，形象成为场景里的本人，身份成为成员署名，选定家务成为家中的小物件。始终让输入或选择是主角。

## 当前问题与边界

现有 AuthIllustratedPage 从 login_household_battle 整张海报裁出人物，用 36pt 渐隐处理下缘；独立底色与海报纹理不同，顶边仍有色差，人物脚下被渐隐。应重做适配的完整场景资产，不再扩大渐隐范围掩盖问题。文字、按钮、协议全部保留为原生可访问控件，不烘焙进图片。

CreateFamilyView 当前将家庭名、昵称、形象、身份放在一个长页面。JoinFamilyView 另有邀请码验证和申请审核，因此不能简单复制创建分支。

仅沿用已支持的邮箱验证码与 Apple 登录。不照抄参考图中的手机号、微信入口，不增加性别采集、通知授权或订阅拦截。邮箱和 Apple 仍按现有独立账号规则处理。

## 全流程

### A. 第一次创建家庭

欢迎页 → 家庭名称 → 你的昵称 → 选择形象 → 家庭身份 → 选择家务 → 本机小家准备好了。

最后提供「开始体验」；需要邀请家人或同步时再登录，登录成功继续原动作并保留草稿。已经登录的用户完成资料后创建正式家庭，再进入邀请或首页。设置步骤不逐页提交到服务端，避免产生半成品家庭。

| 页 | 当页唯一任务 | 标题方向 | 视觉反馈 |
| --- | --- | --- | --- |
| 家庭名称 · 1/5 | 填家庭名称 | 给这个家起个名字 | 简洁家门场景，门牌随输入变化 |
| 你的昵称 · 2/5 | 填昵称 | 在家里，怎么称呼你？ | 人物旁出现昵称，保持输入框明确 |
| 选择形象 · 3/5 | 选一个形象 | 今天，你是哪位主角？ | 单个较大预览与下方头像列表，选中即切换 |
| 家庭身份 · 4/5 | 选一个称谓，可自定义 | 你在家里的身份是？ | 成员署名与角色合为一体，不按性别筛选 |
| 选择家务 · 5/5 | 选择常用家务 | 从哪些小事开始？ | 日常、宠物、育儿、恋爱沿用现有主题；清楚显示已选数量 |
| 准备完成 | 开始体验或继续邀请 | 我们的小家，准备好了 | 完整的小家场景回收前面输入，区分本机草稿和正式家庭 |

页面上方保持一段简短、有人情味的标题；功能价值主要由场景变化和真实内容预览表达。详细产品解释放在审阅说明中，不让每步变成冗长教学。家务页可展开其他主题，不把一项家务拆成一页，也不增加连续的主题问卷。

### B. 加入已有家庭

欢迎页 → 8 位邀请码 → 显示已匹配家庭并确认 → 昵称 → 形象 → 身份 → 登录（尚未登录时）→ 明确提交申请 → 等待家人审核 → 进入家庭。

邀请码无效或过期时留在原页处理，不让用户填完个人资料后才发现加入不了。确认家庭的预览只展示当前接口允许的信息，不泄露成员隐私。不要求改家庭名称，也不让新成员重设全家的家务。等待审核页应有刷新状态、撤回申请、切换家庭的明确去向；重复点击不重复发申请。

### C. 已有账号回来

欢迎页「登录已有账号」→ 邮箱 / Apple → 验证 → 恢复家庭或待审核状态。

邮箱路径为邮箱输入 → 验证码输入；允许返回修改邮箱、重发倒计时、错误重试。登录后已有家庭者直接进入，不再填写昵称、身份或选择家务；没有家庭者回到创建 / 加入选择。

## 视觉标准

欢迎与登录：同一场景、同一底色、同一光感；人物完整，顶部到底部无横向图片边界。标题仍为「家庭保卫战」。欢迎页以创建为主、加入为次，老用户登录保持清楚可见。登录页让邮箱和 Apple 入口成为操作主体，不用过大的插画把它们挤到屏幕外。

资料页：顶部返回和轻量进度；中部为精简场景与一个主要输入或选择区域；底部固定一个主操作。场景不用外框，表单不套大卡片，按钮减少厚重投影。黄色作为主操作，蓝、绿、珊瑚色用于人物和生活物件，文字以高对比黑白为主。

输入页弹出键盘时缩小顶部场景，保留标题、输入框和下一步；不挤压输入框。选择页维持稳定位置，头像变化不推动按钮。大字模式允许垂直滚动与列数调整；浅深色单独验收。动效只用轻量出现、门牌更新、人物加入，尊重减少动态效果设置。

## 交互底线

- 返回保留本地已填资料；中途退出提供继续填写，而不是从头开始。
- 不用假默认昵称代替必填；家庭身份允许中性称谓或自定义，形象与身份不绑定。
- 输入就地校验，错误放在对应字段旁；具体长度和字符范围服从当前服务端校验。
- 资料步骤只推进本地草稿；创建家庭与提交申请是明确的最终动作。
- 协议不预勾选，链接独立可点；取消授权回到当前步骤，保留草稿。
- 登录只负责验证账号；不会偷偷合并邮箱与 Apple 账号，也不会替换现有家庭。
- 所有图文和控件可访问，触控范围至少 44pt。
