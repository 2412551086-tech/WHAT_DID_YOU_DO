# 2026-08-05 MVP 功能与体验收口

## 家庭与账号

- 登录页和“我的”页面支持修改开发账号昵称。
- ACTIVE MEMBER 可以退出当前家庭；OWNER 必须先转让一家之主。
- 家主转让成功后，当前页面立即刷新角色、成员标识和管理权限，不再要求重启 App。
- 任意 ACTIVE 成员开通测试高级版后，同一家庭全部 ACTIVE 成员共享权益。

## 家务目录与常用区

- 系统家务按家庭、恋爱、育儿、宠物四主题组织，全部可免费记录。
- 免费家庭最多 6 项共享常用家务和 2 项自定义家务；高级家庭常用家务不限数量、自定义家务最多 10 项，并支持成员个人布局。
- 常用区只展示已有自定义家务和接下来的 2 个空白入口。
- 统一常用卡片和耗时弹窗的新版插画映射，清除旧 SF Symbol、高级角标和图片外缘黑底。
- 长按排序保留圆角拖动预览，并支持拖入底部垃圾区移出常用。

## 记录与高级倍率

- 耗时弹窗继续支持 1...180 分钟实际耗时和按家务保存上次选择。
- 免费版使用系统默认积分倍率。
- 家庭高级版可为本次记录调整 0.5x...2.0x 倍率，预计积分实时更新。
- API 新增可选 `pointsMultiplier`；后端校验家庭高级权益后按 `round(actualMinutes * pointsMultiplier)` 入账，免费家庭伪造请求返回 403。
- 免费/高级权益对比页和兑换成功页增加积分倍率说明。

## 数据与展示

- 首页使用家庭时区内的本周记录和排行榜。
- 月报支持切换历史月份，展示主题圆环、家务大类分布，并让领跑者立绘跟随当月积分第一名。
- 家庭动态支持表情回应、回应成员头像、软删除和删除后统计刷新。

## 验证

- 后端 build 与 Jest 通过。
- 后端 e2e 通过，覆盖高级倍率权限与计算。
- iOS Simulator XCTest 完整通过；保留既有 Keychain 环境跳过条件。
