# Project Status

更新时间：2026-09-04

## 当前阶段

项目处于“生产后端已上线，MVP 进入真实登录联调与发布准备”阶段。

- iOS：SwiftUI + MVVM，支持 Mock/API 模式切换。
- 后端：NestJS + Prisma + PostgreSQL；生产 API 已部署到 `https://api.douxiaolang.com`。
- 包管理器：统一使用 `pnpm`，不要与 npm 混用。
- 当前认证：统一 `User + AuthIdentity`；国内预留 Apple/微信/邮箱，海外预留 Apple/Google/邮箱。DEV 登录仅保留开发使用。
- 统一身份基础：`AuthIdentity`、多 Provider 映射、绑定冲突、注销级联和会话撤销已完成；邮箱 OTP 端到端代码已接入，Apple/微信/Google 仍待接入。
- 首次使用：首次启动不显示登录页；创建路径支持本地草稿、最多 6 项家务和离线记录，加入路径支持登录前邀请码预览。
- 会话安全：Access Token 15 分钟，Refresh Token 30 天滑动且单次会话最长 90 天；支持 Rotation、重放撤销、多设备登录、当前设备/全部设备退出和 iOS 提前静默刷新。
- 当前发布状态：尚未进入 TestFlight。

## 已完成的 MVP 主链路

1. 首次启动直接选择创建或加入家庭；开发测试身份可复用同一开发用户。
2. 创建家庭，创建者自动成为 `ACTIVE + OWNER`（一家之主）。
3. 展示并复制家庭 `inviteCode`。
4. 其他用户使用 `inviteCode` 申请加入，初始状态为 `PENDING + MEMBER`。
5. OWNER 查看申请并执行 approve/reject。
6. ACTIVE 成员读取全部 36 项免费系统家务，并按四主题选择家庭常用项。
7. 点击家务后使用滚轮选择 1 到 180 分钟实际耗时。
8. `actualMinutes` 按家务分别保存在 UserDefaults，下次打开沿用上次确认值。
9. 创建记录时按实际耗时比例计算并保存积分。
10. 首页读取本周动态 `range=week`，家庭动态继续读取 `range=recent`。
11. 查看日/周/月排行榜，并可切换查看当前或历史月份月报。
12. 家务动态展示成员身份、头像占位、实际耗时、积分和点赞头像。
13. 点赞和取消点赞均为幂等操作。
14. 创建者可左滑删除自己的记录，OWNER 可删除家庭内任意记录。
15. 删除采用软删除；已删除记录不参与日/周/最近动态、排行榜和月报。
16. API 请求具有 loading、error 和 DebugPanel 诊断状态。
17. 免费账号每个家庭可创建 2 个基础共享自定义家务并叠加成就奖励；测试高级账号产品显示不限、服务端保护上限 100，支持图标、统计大类、默认时长、积分倍率、编辑和归档。
18. OWNER 可从目标成员详情页将一家之主转让给另一位 ACTIVE MEMBER。
19. ACTIVE 成员可切换配套人物立绘与头像，后端统一保存 avatarKey。
20. 创建家庭后，OWNER 从四主题家务库配置常用家务；免费版可选 1...6 项并同步给全家，高级版系统家务不限数量且每位成员可保存个人布局，后续从“记一下”页底部继续进入家务库调整。
21. 常用页只展示已创建的自定义家务和接下来的 2 个空白位置，避免高级版出现 10 张空卡。
22. 已实现家庭共享高级权益与原生对比页；任意 ACTIVE 成员开通后全家可用，超过免费 6 项、免费创建自定义家务、免费普通成员尝试编辑布局时触发。
23. 月度战报按所选月份返回主题分布与家务大类分布；主题使用圆环图，大类使用分段比例条和图例。
24. 月度战报仅保留领跑者卡为主视觉，其余摘要、结构和排行降低层级，避免所有色块同时抢焦点。
25. OWNER 可直接编辑家庭名称；所有 ACTIVE 成员可进入本人或其他成员详情查看其滚动近 30 天未删除家务记录。
26. 认证页根据发行区域显示三个 Provider；昵称在创建/加入家庭流程或个人页修改。
27. 耗时选择器展示系统积分倍率；家庭高级版可按本次难度调整 0.5x...2.0x，后端校验权益并按实际耗时入账。
28. ACTIVE MEMBER 可退出家庭；OWNER 必须先转让家主，转让完成后角色和管理入口无需重启即可刷新。
29. 创建/加入家庭流程和个人页均可修改当前开发用户昵称。
30. App 外观支持跟随系统、浅色和深色三种模式，核心 DesignSystem 表面、文字、描边和阴影会自适应。
31. “记一下”页已收口轻触记录、正常滚动、长按进入布局、拖动排序/删除和底部进入家务库的手势边界，并补充自动化测试。
32. 高级家庭成员可在“沿用一家之主布局”和个人常用布局之间切换；免费家庭仍由 OWNER 统一同步。
33. MEMBER 退出家庭后保留原 FamilyMember 历史关系并标记 `LEFT`；再次申请会复用原关系，不按昵称匹配身份。
34. 新建记录保存创建者昵称、身份和头像快照；历史昵称和家庭身份保留记录发生时的快照，头像则跟随该成员当前 `avatarKey`，换形象后既有动态与回应头像同步更新；成员退出时回退使用记录快照。
35. 成就阶段 1–7 的本地工程实现已完成：除成长、专长、互动、协作和搭档成就外，后端已提供家庭长期里程碑、5 个隐藏彩蛋、退出/重入归档、账户注销清理、成就档案、DIRTY 对账修复、死信/积压健康检查和家庭灰度开关。
36. “我的”页面新增账户与安全二级入口，集中管理退出家庭、退出登录与永久注销；注销会删除后端个人数据并清理本机 Keychain、API 缓存和待同步队列。
36. iOS 成就中心已重构为统一三列徽章墙：已获得项优先，其后为未解锁项，带容量奖励的未解锁项优先；点按徽章查看名称、获取条件、进度、奖励和解锁日期。Home 与成就页均可横向滑动查看最多 3 项即将完成目标。
37. 成就解锁反馈改为页面中央弹层；同批次多项解锁可左右滑动查看。成就是否向家庭成员展示采用成员级总开关，不再提供逐枚开关。
38. iOS 已在 Asset Catalog 接入 27 枚正式成就素材；其余规则暂复用对应主题素材，47 枚完全独立资源及统一微调仍属于视觉收口。
39. 首页“家庭本周总积分”和个人“本周积分/完成/家庭排名”统计卡可进入二级周报。家庭周报包含每日走势、成员贡献、家务结构与本周动态；个人周报包含个人排名、常做家务、主要投入、平均耗时、家务结构与个人本周动态。
40. 家庭动态时间改为按家庭时区显示明确的“周几 HH:mm”，不再使用“几小时前/几天前”。
41. “我的”人物卡背景跟随 13 套人物形象的稳定主色；“我的成就”入口不再显示完成数量；家庭成员区包含自己在内的所有头像均可进入同一成员动态详情。
42. 家务记录创建人可从动态左滑编辑实际耗时和高级倍率；保存后刷新周统计、月报并异步重新评估成就。
43. 创建新家庭支持免登录本机体验：家务配置和记录跨 App 重启保存，认证后通过幂等认领接口升级为正式家庭。
44. 加入已有家庭支持先输入邀请码并查看公开预览，用户确认加入时才触发认证。
