# Project Status

更新时间：2026-08-10

## 当前阶段

项目处于“本地可联调 MVP 正确性收口完成，进入稳定性与发布准备”阶段。

- iOS：SwiftUI + MVVM，支持 Mock/API 模式切换。
- 后端：NestJS + Prisma + PostgreSQL，本地端口默认为 `3000`。
- 包管理器：统一使用 `pnpm`，不要与 npm 混用。
- 当前认证：手机号开发登录/显示名 Mock 登录，不是真实短信验证码。
- 当前发布状态：尚未进入 TestFlight。

## 已完成的 MVP 主链路

1. 手机号开发登录，同一手机号复用同一开发用户。
2. 创建家庭，创建者自动成为 `ACTIVE + OWNER`（一家之主）。
3. 展示并复制家庭 `inviteCode`。
4. 其他用户使用 `inviteCode` 申请加入，初始状态为 `PENDING + MEMBER`。
5. OWNER 查看申请并执行 approve/reject。
6. ACTIVE 成员读取全部 36 项免费系统家务，并按四主题选择家庭常用项。
7. 点击家务后使用滚轮选择 1 到 180 分钟实际耗时。
8. `actualMinutes` 按家务分别保存在 UserDefaults，下次打开沿用上次确认值。
9. 创建记录时按实际耗时比例计算并保存积分。
10. 首页读取本周动态 `range=week`，家庭动态继续读取 `range=recent`。
11. 查看日/周/月排行榜，并可切换查看当前或历史月份月报。
12. 家务动态展示成员身份、头像占位、实际耗时、积分和点赞头像。
13. 点赞和取消点赞均为幂等操作。
14. 创建者可左滑删除自己的记录，OWNER 可删除家庭内任意记录。
15. 删除采用软删除；已删除记录不参与日/周/最近动态、排行榜和月报。
16. API 请求具有 loading、error 和 DebugPanel 诊断状态。
17. 免费账号每个家庭可创建 2 个共享自定义家务；测试高级账号可创建 10 个，支持 10 项图标、统计大类、默认时长、积分倍率、编辑和归档。
18. OWNER 可从目标成员详情页将一家之主转让给另一位 ACTIVE MEMBER。
19. ACTIVE 成员可切换配套人物立绘与头像，后端统一保存 avatarKey。
20. 创建家庭后，OWNER 从四主题家务库配置常用家务；免费版可选 1...6 项并同步给全家，高级版系统家务不限数量且每位成员可保存个人布局，后续从“记一下”页底部继续进入家务库调整。
21. 常用页只展示已创建的自定义家务和接下来的 2 个空白位置，避免高级版出现 10 张空卡。
22. 已实现家庭共享高级权益与原生对比页；任意 ACTIVE 成员开通后全家可用，超过免费 6 项、免费创建自定义家务、免费普通成员尝试编辑布局时触发。
23. 月度战报按所选月份返回主题分布与家务大类分布；主题使用圆环图，大类使用分段比例条和图例。
24. 月度战报仅保留领跑者卡为主视觉，其余摘要、结构和排行降低层级，避免所有色块同时抢焦点。
25. OWNER 可直接编辑家庭名称；所有 ACTIVE 成员可进入其他成员详情查看其滚动近 30 天未删除家务记录。
26. 手机号登录页只输入手机号和开发占位验证码；昵称在创建/加入家庭流程或个人页修改。
27. 耗时选择器展示系统积分倍率；家庭高级版可按本次难度调整 0.5x...2.0x，后端校验权益并按实际耗时入账。
28. ACTIVE MEMBER 可退出家庭；OWNER 必须先转让家主，转让完成后角色和管理入口无需重启即可刷新。
29. 创建/加入家庭流程和个人页均可修改当前开发用户昵称。
30. App 外观支持跟随系统、浅色和深色三种模式，核心 DesignSystem 表面、文字、描边和阴影会自适应。
31. “记一下”页已收口轻触记录、正常滚动、长按进入布局、拖动排序/删除和底部进入家务库的手势边界，并补充自动化测试。
32. 高级家庭成员可在“沿用一家之主布局”和个人常用布局之间切换；免费家庭仍由 OWNER 统一同步。
33. MEMBER 退出家庭后保留原 FamilyMember 历史关系并标记 `LEFT`；再次申请会复用原关系，不按昵称匹配身份。
34. 新建记录保存创建者昵称、身份和头像快照；成员改名、换形象、退出或重新加入后，历史动态仍保留记录发生时的展示信息。
