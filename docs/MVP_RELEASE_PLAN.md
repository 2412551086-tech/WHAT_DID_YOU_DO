# 家庭保卫战 MVP 发布计划

更新时间：2026-09-03

## 1. 当前结论

项目已经完成本地可联调 MVP 的主要产品链路，可以进入“发布版本收口”阶段，
但尚未达到直接提交 App Store 的条件。ICP备案已经通过，App 备案正在审核，
服务器与域名已经具备；接下来重点是冻结代码基线、生产认证、服务端部署、
成就系统收口、语音输入、发布合规与 TestFlight 灰度。

## 3. 推荐开发顺序

| 阶段 | 预计时间 | 主要工作 | 阶段验收 |
| --- | --- | --- | --- |
| 0. 冻结基线 | 2–3 天 | 清理工作区、修复成就 E2E、接入幂等 Key、建立发布分支 | iOS/后端构建、单元、E2E、Smoke 全绿并形成基线提交 |
| 1. 首次使用与账号底座 | 4–6 天 | 免登录 onboarding、本地草稿认领、`AuthIdentity`、会话与冲突处理 | 本地体验跨重启，认证后无损升级且重复请求不重复导入 |
| 2. Apple 与邮箱认证 | 5–8 天 | AuthenticationServices、邮箱验证码、服务端验签、绑定和撤销 | 国内外均可注册、登录、续期、退出和注销 |
| 3. 微信登录 | 5–8 天 | 国内微信 SDK、Universal Link、服务端换票和账号绑定 | 真机微信登录、取消、失败、绑定冲突和注销通过 |
| 4. Google 登录 | 3–5 天 | 海外 Google 授权、服务端验签和账号绑定 | 海外构建 Provider 与认证链路通过 |
| 5. 预发布部署 | 3–5 天，可与 2–4 并行 | staging/production、HTTPS、PostgreSQL、迁移、备份和监控 | 从公网真机完成双账号家庭主链路，备份可恢复 |
| 6. 成就收口 | 4–7 天，可并行 | UI 微调、徽章补齐、隐藏成就、灰度和告警 | 规则自动化全绿，浅/深色和小屏验收通过 |
| 7. 语音输入 | 4–7 天 | “拖地二十分钟”识别、预填和确认，不自动提交 | 中文识别、拒绝权限、断网、误识别和取消流程通过 |
| 8. 发布加固 | 5–8 天 | 双账号 XCUITest、弱网、离线、迁移、隐私清单和安全检查 | Release 配置无开发入口，完整回归和归档通过 |
| 9. TestFlight | 7–14 天 | 内部两台真机，再扩大灰度 | 登录、同步、成就和注销稳定，无 P0/P1 缺陷 |
| 10. App Store 提交 | App 备案通过后 | 构建、截图、描述、隐私标签、审核账号和说明 | App Store Connect 校验通过并提交审核 |

## 4. 必须由产品负责人完成或授权的事项

- 邮件服务商账号、发信域名验证和验证码模板。
- Apple Developer 中启用 Sign in with Apple，并创建对应 Key/配置。
- 微信开放平台移动应用审核、App ID、App Secret 和 Universal Link 配置。
- 提供生产域名、服务器访问方式和 DNS/HTTPS 管理权限。
- App 备案结果、隐私政策/用户协议主体信息和客服联系方式。
- 决定首版是否收费；若收费，提供 App Store Connect 订阅产品配置。

### 环境说明

- 本机 iOS 26.5 Simulator Runtime 在设备启动后会异常退出，XCTest 无法进入运行阶段；
  这是模拟器系统组件故障，不是项目编译失败。正式进入下一阶段前，应在修复或重装运行时后补跑 XCTest。
- iOS 17.0 模拟器低于项目最低部署版本 iOS 17.6，不能作为替代执行环境。
- 后端全量 E2E 仍会输出 `pg` 并发查询弃用警告，但不影响本次 29 项用例通过；应在发布加固阶段清理。
