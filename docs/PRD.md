# 《你今天干啥啦》App PRD 完整版 v1.0

## 1. 产品概述

### 1.1 产品名称

你今天干啥啦

### 1.2 产品定位

《你今天干啥啦》是一款面向家庭成员的家务劳动量记录、评估与共享 App。

产品通过家务数据库、家务时长评估、积分换算、语音输入、每日重复任务、常做事项快捷记录、月度报告等功能，把家庭中的隐形劳动转化为可视化数据。

用户可以在家庭空间中记录自己完成的家务，家庭成员可以共享查看彼此的工作量、积分排行和月度家务报告。产品整体采用 **诙谐幽默的表达方式**，搭配 **卡片化首页、新粗野主义 UI、新拟物质感滤镜风格**，让家务记录不再像严肃考核，而像一个家庭内部的轻松互动工具。

### 1.3 产品核心理念

家务不是没人做，只是没人记。

本产品希望解决家庭生活中“家务劳动不可见、不好衡量、容易引发争议”的问题，让每一次洗碗、拖地、做饭、倒垃圾、浇花、照顾家人等劳动都有记录、有积分、有反馈。

### 1.4 产品关键词

家庭共享、家务记录、劳动量评估、积分系统、月度报告、语音输入、每日重复任务、常做事项、卡片化 UI、诙谐幽默、新粗野主义、新拟物质感、iOS 优先、免费加付费解锁。

## 2. 产品背景与痛点

### 2.1 用户痛点

家庭家务劳动中经常存在以下问题：

1. 家务劳动很多是隐形劳动，做了但没人看见。
2. 家庭成员之间容易因为“谁干得多，谁干得少”产生争议。
3. 传统家务分工方式缺少可量化依据。
4. 每次手动记录家务容易麻烦，用户难以长期坚持。
5. 不同家庭有很多特殊家务，系统默认数据库不一定覆盖。
6. 家务记录如果过于严肃，容易让家庭关系变紧张。
7. 家庭成员希望有一种轻松、不指责、有趣的方式看见彼此付出。

### 2.2 产品解决方案

《你今天干啥啦》通过以下方式解决上述问题：

1. 建立家务数据库，为每项家务设置标准时长和积分。
2. 支持家庭共享，让成员之间看到彼此家务工作量。
3. 支持每日常做任务和一键记录，降低记录成本。
4. 支持语音输入“我干了什么”，快速生成家务记录。
5. 支持自定义常干事项，让每个家庭的特殊劳动被记录。
6. 支持月度报告，形成家庭劳动总结和反馈。
7. 采用幽默文案，降低工具的严肃感和冲突感。
8. 通过免费版和付费版区分基础功能与高级个性化功能。

## 3. 产品目标

### 3.1 MVP 阶段目标

iOS 版本优先上线，完成以下核心闭环：

1. 用户可以通过微信、Apple ID、手机号登录。
2. 用户可以创建家庭或加入家庭。
3. 用户可以在家庭中记录家务。
4. 用户可以通过手动选择、常做事项、每日重复任务、语音输入等方式记录家务。
5. 系统根据家务数据库评估标准时长。
6. 系统将家务时长换算为积分。
7. 家庭成员可以看到彼此的家务记录、积分和排行。
8. 每月自动生成家庭月度报告。
9. 免费用户可以使用核心 10 个家务事项。
10. 付费用户可以解锁更多家务数据库和自定义常干事项。
11. 创建家庭时可设置是否需要图片作为家务记录凭证，默认不需要。
12. 首页采用卡片化 UI，视觉风格为新粗野主义 + 新拟物质感。

### 3.2 用户体验目标

1. 用户完成一次普通家务记录应控制在 5 到 15 秒内。
2. 高频家务可以通过首页卡片一键记录。
3. 用户可以用一句语音同时记录多个家务。
4. 家庭成员可以清楚看到今日、本周、本月家务贡献。
5. 免费用户可以完成基础使用闭环。
6. 付费用户获得更完整、更个性化的记录体验。
7. 产品文案应幽默但不羞辱，调侃但不激化矛盾。

## 4. 目标用户与使用场景

### 4.1 目标用户

#### 核心用户

1. 同居情侣
2. 已婚夫妻
3. 有孩子的家庭
4. 多人合租家庭
5. 与父母同住的成年子女

#### 潜在用户

1. 希望培养孩子做家务的家庭
2. 希望改善家庭分工的用户
3. 喜欢生活记录和数据统计的用户
4. 喜欢幽默风格工具 App 的用户
5. 对家庭积分、家庭奖励机制感兴趣的用户

### 4.2 典型用户画像

#### 用户 A：同居情侣

痛点：总觉得自己做得更多，但对方不一定意识到。
需求：希望有一个轻松工具记录谁做了什么。
场景：下班后记录“洗碗”“拖地”“倒垃圾”。

#### 用户 B：已婚夫妻

痛点：家务分配不透明，容易因为“谁更累”争论。
需求：希望每月能看到家庭劳动统计。
场景：月底查看家庭家务月报。

#### 用户 C：有孩子的家庭

痛点：孩子不主动做家务，缺少正向激励。
需求：希望用积分、排行榜、称号鼓励孩子参与。
场景：孩子完成“整理玩具”“浇花”“收拾书桌”后获得积分。

#### 用户 D：养宠家庭

痛点：铲屎、遛狗、喂猫等劳动高频但容易被忽略。
需求：希望记录宠物相关劳动。
场景：高级版解锁宠物类家务或自定义事项。

## 6. 商业模式设计

### 6.1 商业模式定位

产品采用 **免费版 + 付费解锁高级功能** 的模式。

免费版保证用户可以完成基础家务记录闭环，付费版提供更多家务类型、更高个性化能力和更丰富的数据报告。

### 6.2 免费版可用范围

免费用户可以使用：

1. 微信、Apple ID、手机号登录。
2. 创建或加入家庭。
3. 使用核心 10 个免费家务事项。
4. 手动记录家务。
5. 使用基础每日重复任务。
6. 使用基础常做事项。
7. 使用语音输入识别核心 10 个家务。
8. 查看家庭动态。
9. 查看基础排行榜。
10. 查看基础月度报告。
11. 创建家庭时设置是否需要图片凭证。
12. 使用默认首页卡片布局。
13. 使用基础幽默文案。

### 6.3 付费版解锁内容

付费用户可以解锁：

1. 完整家务数据库。
2. 自定义常干事项。
3. 家庭共享自定义事项。
4. 更多每日重复任务。
5. 语音识别完整数据库和自定义事项。
6. 高级月度报告。
7. 更多幽默称号。
8. 更多报告分享模板。
9. 更多首页卡片样式。
10. 更多主题皮肤。
11. 更细的数据统计。
12. 后续高级 AI 功能优先体验。

## 11. 家庭空间模块

### 11.1 创建家庭

用户首次登录后可以创建家庭。

创建家庭字段：

| 字段       | 类型 | 是否必填 | 默认值  | 说明          |
| -------- | -- | ---- | ---- | ----------- |
| 家庭名称     | 文本 | 是    | 无    | 例如“王家家务委员会” |
| 家庭头像     | 图片 | 否    | 默认头像 | 可后续修改       |
| 是否需要图片凭证 | 开关 | 否    | 关闭   | 默认不需要       |
| 邀请成员     | 按钮 | 否    | 无    | 创建后邀请成员     |

### 11.2 图片凭证规则

创建家庭时新增设置：

**是否要求家务记录上传图片凭证**

默认值：

**不需要**

#### 关闭状态

用户记录家务时可以不上传图片。

文案：

信任模式开启：这个家选择相信人类。

#### 开启状态

用户记录家务时必须上传至少 1 张图片。

文案：

证据模式开启：每一块被擦过的桌子，都要留下影像资料。

### 11.3 家庭设置中修改图片凭证规则

路径：

我的 > 家庭设置 > 记录家务时需要图片凭证

规则：

1. 默认关闭。
2. 创建者和管理员可以修改。
3. 普通成员只能查看，不能修改。
4. 修改后只影响后续新增记录。
5. 历史记录不受影响。

设置页文案：

关闭状态：当前为信任模式，大家说干了，就先记上。
开启状态：当前为证据模式，没图没真相。

### 11.4 邀请成员

家庭创建成功后，系统生成：

1. 邀请码
2. 邀请链接
3. 邀请二维码

用户可以通过微信、复制链接、二维码等方式邀请成员加入。

### 11.5 加入家庭

用户可以通过以下方式加入家庭：

1. 输入邀请码
2. 点击邀请链接
3. 扫描二维码

加入前展示：

1. 家庭名称
2. 家庭头像
3. 当前成员数量
4. 是否开启图片凭证规则

## 17. 积分系统

### 17.1 基础公式

积分 = 标准时长 × 难度系数 × 修正系数 × 数量

默认：

1 分钟家务 = 1 基础积分。

### 17.2 示例

洗碗：

15 分钟 × 1.0 = 15 分

做饭：

45 分钟 × 1.3 = 59 分

清理卫生间：

30 分钟 × 1.5 = 45 分

浇花：

8 分钟 × 1.0 = 8 分

### 17.3 修正系数

| 场景    | 修正系数 | 示例     |
| ----- | ---: | ------ |
| 普通完成  |  1.0 | 日常洗碗   |
| 深度清洁  |  1.3 | 厨房大扫除  |
| 夜间完成  |  1.2 | 半夜收拾   |
| 节假日完成 |  1.2 | 过年大扫除  |
| 高体力消耗 |  1.3 | 搬重物    |
| 高情绪消耗 |  1.5 | 陪孩子写作业 |

### 17.4 防刷分机制

1. 同一用户同一类型家务短时间内频繁提交时，系统提示确认。
2. 部分家务设置每日上限。
3. 每日重复任务可设置每日计分上限。
4. 自定义高积分事项需要管理员确认。
5. 家庭成员可以对记录进行“存疑”。
6. 被多人存疑的记录进入待确认状态。
7. 管理员可以编辑、确认或删除异常记录。
8. 语音一次识别多个任务时必须人工确认。
9. 系统记录每条任务来源：手动、语音、一键、每日重复。

### 17.5 异常提示文案

1. 你今天已经倒了 5 次垃圾，是垃圾桶成精了吗？
2. 系统检测到你 3 分钟内洗了 4 次碗，请问你家是开饭店的吗？
3. 这个积分有点豪放，建议家庭管理员看一眼。
4. 这条记录有点神秘，建议家庭会议轻轻审判一下。

### 26.4 家务记录接口

#### 创建家务记录

POST /api/v1/chore-records

提交时校验：

1. 当前用户是否有权限使用该家务。
2. 如果家务为 premium，检查用户订阅状态。
3. 如果家庭开启 require_photo_proof，检查 image_urls 是否为空。
4. 检查每日上限。
5. 检查异常频率。

错误码：

| 错误码                  | 说明           |
| -------------------- | ------------ |
| PREMIUM_REQUIRED     | 该家务需要高级版     |
| PHOTO_PROOF_REQUIRED | 当前家庭要求上传图片凭证 |
| DAILY_LIMIT_REACHED  | 今日计分上限已达     |
| PERMISSION_DENIED    | 无权限操作        |
| CHORE_NOT_FOUND      | 家务不存在        |

#### 获取家庭动态

GET /api/v1/chore-records/feed

#### 删除记录

DELETE /api/v1/chore-records/{id}

#### 存疑记录

## 30. 非功能需求

### 30.1 性能需求

1. 首页加载时间不超过 2 秒。
2. 家务记录提交响应时间不超过 1 秒。
3. 语音识别结果返回尽量控制在 3 秒内。
4. 月度报告可异步生成。
5. 图片上传需要压缩处理。
6. 首页卡片滚动保持流畅。

### 30.2 安全与隐私

1. 家庭数据仅家庭成员可见。
2. 用户手机号、登录标识等敏感信息加密存储。
3. 图片凭证安全存储。
4. 用户可删除自己的记录。
5. 家庭创建者可移除成员。
6. 退出家庭后不可再访问家庭数据。
7. 提供账号注销能力。
8. 语音数据应明确用途，尽量不长期保存原始音频。
9. 订阅和支付信息遵守平台规范。

### 30.3 兼容性

MVP 优先支持：

1. iOS 16 及以上
2. iPhone 主流机型
3. 暂不优先适配 iPad
4. 暂不开发 Android
5. 暂不开发小程序

## 31. 风险与解决方案

### 31.1 风险：用户觉得记录麻烦

解决方案：

1. 首页提供常做事项卡片。
2. 高频任务支持一键记录。
3. 每日重复任务自动展示。
4. 支持语音输入。
5. 支持一键重复上次记录。

### 31.2 风险：积分规则引发争议

解决方案：

1. 展示积分计算逻辑。
2. 提供默认规则。
3. 管理员可调整部分规则。
4. 异常记录支持存疑。
5. 自定义高积分事项需要管理员确认。

### 31.3 风险：幽默文案引发不适

解决方案：

1. 文案调侃行为，不攻击人。
2. 低贡献用户以鼓励为主。
3. 提供温柔模式和毒舌模式，二期。
4. 用户可关闭吐槽文案，二期。

### 31.4 风险：图片凭证增加不信任感

解决方案：

1. 默认关闭图片凭证。
2. 创建家庭时明确说明规则。
3. 可以在家庭设置中修改。
4. 文案强调“家庭规则”，避免审判感。
5. 图片凭证不做默认强制。

### 31.5 风险：免费版过于受限导致流失

解决方案：

1. 核心 10 个家务必须覆盖高频场景。
2. 免费用户可完整体验记录、排行、基础月报。
3. 付费点放在“更多”和“个性化”上，不破坏基础闭环。
4. 高级家务展示锁定，让用户知道付费价值。

### 31.6 风险：UI 风格过强影响可用性

解决方案：

1. 新粗野主义用于视觉识别，不牺牲阅读性。
2. 核心按钮保持清晰。
3. 色彩高对比但不刺眼。
4. 卡片之间保持足够间距。
5. 数据展示优先保证易读。

## 35. 一句话产品介绍

《你今天干啥啦》是一款卡片化、幽默风格的家庭家务积分 App。用户可以通过微信、Apple 或手机号登录，使用语音、一键按钮、每日重复任务和常做事项快速记录家务，系统会根据家务标准时长换算积分，让家庭成员共享查看彼此劳动量，并自动生成每月家务报告。免费版支持核心 10 个家务，付费版可解锁更多家务数据库和自定义常干事项。
