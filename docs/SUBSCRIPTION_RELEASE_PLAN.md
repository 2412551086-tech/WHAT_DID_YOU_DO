# 家庭高级版发布计划

更新：2026-09-06。本文区分本地代码完成和生产可用，不代表已开通商店订阅。

## 已落地的界面与规则

- 所有既有升级入口复用 `PremiumUpgradeSheet`：我的、常用数量、自定义家务、个人布局、积分倍率。仅顶部一句文案随入口改变。
- 原生系统字体、真实 Logo、独立协作插画、无图标权益表。月度拟价 6 元，年度拟价 49.90 元；未增加买断或虚构免费试用。
- 增加会员管理、订阅说明、协议链接及次级优惠码入口。开发兑换仅在 Debug 显示；生产优惠码待 Apple 官方兑换流程。
- 免费基础容量调整为 8 项系统常用家务 + 2 项自定义，成就奖励继续叠加。本地体验和后端认领分别校验两类上限，不能互相挪用。
- 高级版自定义产品显示不限，现有服务端保留 100 项保护上限；订阅说明披露该限制。语音输入仍为规划中，不作为已交付权益。
- 购买、恢复与正式优惠码当前只给出未开放提示，不调用扣款、不伪造交易、不授予付费权益。
- App 协议入口指向 `https://douxiaolang.com`；`website/` 包含首页、隐私、条款、订阅和支持页草稿及发布校验。未部署公网。

## 实现约束

拟定商品标识可用 `familyguard.premium.monthly` / `familyguard.premium.yearly`，须先核对 App Store Connect 中已有商品，不能重复创建或假定已存在。

服务端应使用 Apple 官方 App Store Server Library 校验签名交易及通知，检查证书链、bundleId、appAppleId、environment、productId 和 `appAccountToken`。不得信任客户端自行传入的价格、到期日或“购买成功”布尔值。originalTransactionId 唯一绑定稳定 User 与家庭权益关系，跨账号恢复冲突应明确报错，不自动合并用户。

新增订阅/交易/通知持久化表和 forward migration；接入 Server Notifications V2，处理重复、乱序、退款、撤销、计费重试及宽限期，增加定期对账。不以永久 `User.plan = PREMIUM` 代替订阅有效期。敏感交易和密钥不写日志或仓库。

客户端应用启动监听交易更新，购买带上后端确定的 appAccountToken；验证成功后完成交易，断网或后端失败保留待验证交易并可重试。使用 StoreKit 商品 `displayPrice`，不可将拟价硬编码为真实收费价格。恢复购买不重新扣费；已订阅或加载失败时不给出误导购买入口。

推荐共享规则：订阅属于购买账号，权益给予绑定的 App 家庭，不等于 Apple 系统家庭共享。购买时明确受益家庭，重复订阅需提示；更换家庭、取消账号、购买人退出后的权益归属必须在正式计费前确认。到期后保存全部记录、自定义内容与成就奖励，只限制新增/编辑超限配置，不静默删除用户数据。

## 需要补齐的验证

本轮自动化：后端单元 13 套/56 项通过，端到端 2 套/36 项通过；iOS 全量 93 项通过、1 项因无签名 Keychain 权限跳过。SwiftUI 三种尺寸的原生截图已生成并检查，HTML 草稿五页生成成功，`git diff --check` 通过。E2E 仍有现有 PostgreSQL 客户端并发查询弃用警告，串行检测未报告未关闭句柄。

- 当前阶段不做真实扣费测试，也未创建正式商店商品。
- 8+2 规则需先部署后端，再发布客户端；旧后端返回的容量仍作为线上权益表依据。
- 网站正式发布被配置校验拦截，不能拿审核占位页面提交商店。
- 本地 HTML 被内置浏览器安全策略阻止打开，页面仍需人工浏览器视觉验收。
- Simulator 无签名时 Keychain 权限不可用，需要签名真机补测。测试不得削弱真实 Keychain 配置绕过权限。
