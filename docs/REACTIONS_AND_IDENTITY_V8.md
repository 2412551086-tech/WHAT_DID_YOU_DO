# 身份滚轮与家庭回应 V8

日期：2026-09-11。通知系统保持暂缓，原方案保存在 `NOTIFICATION_SYSTEM_REVIEW.md`。

## 交互

身份选项沿圆柱面排布，离中心越远，纵向间距、可见高度及亮度越小；滚动惯性和行对齐保留。中央文字保持正面清晰，减少动态效果模式采用无透视压缩。无声音，仅用户跨行时轻触觉反馈。

六种回应使用统一黄、粉、墨黑的可缩放绘图：点赞、质疑（向下拇指）、击掌、黑脸、笑哭、调侃。轻点回应按钮用于点赞/撤销，长按可选其他回应，重复选择当前回应可撤销。

## 标记规则

当前建议按严格过半实现，待用户对“1/2 以上”的口径确认：阈值为 `floor(当前 ACTIVE 成员数 / 2) + 1`。例如两人家庭需两票，四人家庭需三票。

分母包括记录作者；每个仍在家庭中的成员，每条记录最多一票。只有 `like` 计入点赞票，只有 `doubt` 计入质疑票；其他趣味表情不计入这两个门槛。

- 点赞达到门槛：小花标识及“点赞达标”。
- 质疑达到门槛：温和黄色问号及“待确认”。
- 未达到门槛：不显示多数标记。

撤销、更换回应及成员退出后，重新查询时重新计算标记。不是永久盖章，不自动扣分、删记录，也不判定某人造假。质疑不产生正向回应类成就奖励，原有其他回应的成就语义保留。

## 本机模式

原问题：本机记录的回应仍调用需要登录的云端接口，没有独立本地持久化路径。

现将回应写入本机家庭记录的可选 `reactionKey`，保存成功后才更新页面。旧草稿无需迁移仍可读取；重启、编辑记录、撤销回应时保留正确状态。不请求云端，不伪造其他成员。本机只有一名成员，因此自己的一票达到本机一人门槛。

本机回应不自动上传为云端互动，绑定/切换账号继续遵循工作区隔离方案。来自其他真实成员的互动成就仍需账号数据。

## 接口与兼容

新增回应值 `doubt`；记录列表、动态以及回应结果新增可选 `reactionConsensus`：

```json
{"eligibleMemberCount":4,"requiredCount":3,"likeCount":0,"doubtCount":3,"status":"questioned"}
```

`status` 为 `none`、`appreciated` 或 `questioned`。服务端以 ACTIVE 成员及唯一用户投票计算；客户端不从旧的总回应数 `likeCount` 猜测多数状态。

旧服务器不返回该字段时，普通点赞继续可用，不显示多数标记；质疑操作提示服务器尚未启用。正式云端使用需要同步发布服务端代码，不把仅更新手机称为已上线云端功能。
