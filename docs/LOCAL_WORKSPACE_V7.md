# 本机与账号数据隔离

日期：2026-09-11

## 登录与退出

本机已有家庭时，邮箱或 Apple 登录成功后先显示数据选择页。此时只读取账号家庭，不自动上传本机记录、不修改账号昵称、不删除本机家庭。

- 使用云端家庭：保留本机备份，退出账号后继续本机体验。
- 将本机保存为独立家庭：确认后创建账号下的新家庭，不覆盖已有云端家庭。本机备份仍保留。

中断后重新打开仍回到选择页；读取失败可重试或退出回本机。上传采用按账号隔离的持久化请求快照，超时重试复用同一请求，避免重复家庭。旧版本遗留的认领状态不会再触发自动上传。

目前不提供破坏性的“覆盖云端”。该操作会影响家庭成员和已有记录，应作为独立的数据管理流程设计，不能附带在登录里。

## 本机成就

本机工作区此前没有成就评估入口，不能依赖账号接口获取成就。现由本机记录评估单人成就，按家庭时区计算天数、连续记录、主题与场景进度，并保存首次解锁时间。删除记录不会取消已解锁成就。

记录保存家务分类快照，避免后来修改家务配置改变历史归属。多人协作条件明确需要登录；本机达到角色条件不等于获得会员权益，角色领取和容量奖励仍需账号确认。基础常用家务 8 项、自定义 2 项不变。

## 交互与资产

身份滚轮取消声音，只保留轻触觉反馈。图标透明处理的范围、原图备份和视觉检查见 `ICON_TRANSPARENCY_AUDIT.md`。

本轮仅更新 iOS 与本地设计资产，不修改或清空生产账号数据，不部署后端。
