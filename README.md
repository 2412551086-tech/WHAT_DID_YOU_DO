# What Did You Do Today

Monorepo for a family chore tracking app. The initial scope is:

- `apps/ios`: SwiftUI iOS app structure only, without Xcode project files.
- `backend`: NestJS + TypeScript API service with Prisma and PostgreSQL.
- `docs`: product, API, data model, task, and release documentation.
- `design`: product design artifacts and visual system notes.
- `infra`: deployment and infrastructure notes.

Business features are intentionally not implemented in this initialization step.
