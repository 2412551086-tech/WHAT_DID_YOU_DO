# iOS App

SwiftUI app workspace placeholder.

This directory intentionally does not include Xcode project files yet. The first iOS implementation step should create the SwiftUI project after the navigation structure, deployment target, signing strategy, and module naming are confirmed.

## Planned Structure

- `Sources`: SwiftUI source files after the Xcode project is generated.
- `Resources`: assets, localization, and configuration files.
- `Tests`: unit and UI test files.
